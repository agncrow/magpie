# Contributing

Magpie does not accept outside contributions yet. A contributor license
agreement will come first, so that every line of Magpie can be offered
both under its [source license](LICENSE) and under a commercial one. A
pull request is closed with this note by a workflow, so nobody waits on
one.

What is welcome, in Issues:

- **A bug**, with the program that shows it and what each mode said —
  `crow run -i file.co` and `crow run file.co`. Magpie's answers are held
  to be the same in both, so a difference between them is a bug by itself.
- **A question** the READMEs, REFERENCE.md or PARTS.md do not answer.
- **A suggestion.**
